# 🌟 Personal Portfolio Website

---

## 👋 Hi — I'm Sneha Wani

This is my **Personal Portfolio Website**, built with **Next.js**, showcasing my projects, skills, experience and contact info in a clean, modern UI.

**Role:** Frontend / Full-Stack Developer  


---

## 🚀 Features

- 🎯 Hero Section — short intro + CTA  
- 👩‍💻 About — background, story, interests  
- 🛠️ Projects — demos, GitHub links, tech stack tags  
- 📜 Experience & Certifications  
- ✉️ Contact Form — email or serverless API  
- 📱 Responsive — mobile, tablet, desktop  
- ⚡ Fast & Optimized — image & performance optimizations (Next/Image, code splitting)  
- 🎨 Light & Dark theme toggle (optional)  
- 🧩 Accessibility-minded components

---

## 🧰 Tech Stack

- Next.js
- React
- JavaScript (ES6+)
- Tailwind CSS
- Node.js (optional APIs)
- Vercel / Netlify (deployment)
